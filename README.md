1. Создание проекта Programming в локальном репозитории. Тип проекта Windows Forms Application;
2. Создание двух подпапок в проекте Model и View. Model хранит бизнес-логику, View - формы и сопроводительные классы;
3. Переименование Form1 в MainForm и перемещение в папку View;
4. Добавление в папку Model перечисления дней недели, жанров кино, цветов, форм обучения студента, производителей смартфонов и времен года;
5. На главном окне формы размещаем TabControl с одной вкладкой Enums, выбираем в свойствах элемента Dock и выставляем значение Fill;
6. Для соответствия приложения с макетом добавляем GroupBox, в него помещаем TextLabel (лейблы полей), ListBox (списки), TextBox (поле для ввода);
7. В первый список добавляем перечень всех перечислений;
8. Добавляем в поле ввода вывод индекса выбранного варианта перечисления;
9. Добавляем парсинг дней недели;
10. С использованием интерполяции строк выводим название дня недели и его индекс (т.к. отсчет идет с понедельника, то  прибавляем 6 к индексу, делим на 7 и прибавляем в конце 1, чтобы воскресенье было завершающим днем), если введенные данные не соответствуют названию одного из дней недели, то под текстовым полем ввода появляется сообщение, что такого дня недели нет, а если значение введенных данных пустое, то выводим сообщение о вводе данных;
11. Добавляем интерактивный выбор времени года при помощи switch-кейсов. В выпадающем списке при выборе зимы/лета выводим сообщение, при выборе весны/осени - меняем цвет фона.
